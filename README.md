# Chowdown 🍔🍕🍣

Chowdown is a native Android food ordering application built with Kotlin. It provides a seamless and intuitive user experience for browsing a variety of delicious meals, managing a cart, and placing orders. 

## Features

- **User Authentication:** Secure login and registration using Firebase Authentication.
- **Categorized Menu:** Browse food items by categories such as Burgers, Pizza, Sushi, Desserts, and Drinks.
- **Search Functionality:** Easily find your favorite food with a built-in search feature.
- **Product Details:** View detailed descriptions, prices, and images for each food item.
- **Shopping Cart:** Add items to your cart, review your order, and manage your cart seamlessly.
- **User Profile:** Manage user information and view order history.
- **Firebase Database Integration:** Real-time data sync using Firebase Realtime Database.

## Tech Stack

- **Language:** Kotlin
- **UI:** Android XML Layouts, RecyclerView, CardView, Material Design components.
- **Architecture:** Standard MVC/MVVM patterns.
- **Backend/Database:** Firebase Authentication & Firebase Realtime Database.

## Getting Started

### Prerequisites
- Android Studio (Koala or later recommended)
- Java Development Kit (JDK) 11 or higher
- An active Firebase Project configured for Android.

### Setup Instructions

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ST10458040/WIL-App-Repository.git
   ```

2. **Open in Android Studio:**
   - Launch Android Studio.
   - Select `Open an existing project`.
   - Navigate to the cloned directory and select it.

3. **Firebase Configuration:**
   - Make sure you have your `google-services.json` file added to the `app/` directory (required for Firebase integration).

4. **Build and Run:**
   - Sync the Gradle project files.
   - Select an emulator or physical device.
   - Click the "Run" button to launch the app.
